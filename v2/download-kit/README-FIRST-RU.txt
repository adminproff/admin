OP Kiosk OS 2.0 — КАК СОБРАТЬ ISO ИЗ МАЛЫХ ЧАСТЕЙ
====================================================

Этот комплект используется только для сборки, которая полностью прошла
автоматический цикл проверки установки BIOS и UEFI.

1. Создайте на диске пустую папку, например:

   C:\OP-Kiosk-OS-2.0

2. Скачайте в эту папку ВСЕ файлы одного выпуска:

   OP-Kiosk-OS-2.0.0-...-amd64.iso.part-01.bin
   OP-Kiosk-OS-2.0.0-...-amd64.iso.part-02.bin
   ...
   OP-Kiosk-OS-2.0.0-...-parts.sha256
   OP-Kiosk-OS-2.0.0-...-amd64.iso.sha256
   MERGE-OP-Kiosk-OS-2.0.cmd
   MERGE-OP-Kiosk-OS-2.0.ps1
   DOWNLOAD-INFO.txt

3. Не переименовывайте части. Не смешивайте файлы разных выпусков.

4. Дважды щёлкните:

   MERGE-OP-Kiosk-OS-2.0.cmd

5. Скрипт автоматически:

   - проверит наличие всех частей;
   - проверит SHA-256 каждой части;
   - соберёт единый ISO;
   - проверит размер ISO;
   - проверит итоговый SHA-256.

6. Успешный результат заканчивается сообщением:

   ISO успешно собран и проверен

7. После этого в той же папке появится файл:

   OP-Kiosk-OS-2.0.0-...-amd64.iso

8. Записывайте ISO на USB через Rufus. Когда Rufus предложит режим записи,
   выбирайте режим DD.

ВАЖНО
======

- Для сборки не нужны права администратора.
- Требуется Windows PowerShell 5.1, он уже входит в Windows 10/11.
- Все части должны лежать в одной папке.
- При ошибке SHA-256 повреждённую часть нужно скачать заново.
- До сообщения об успешной итоговой проверке ISO использовать нельзя.
